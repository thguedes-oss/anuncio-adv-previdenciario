# Publicacao no GitHub Pages

## Caminho recomendado

1. Crie um repositorio no GitHub, por exemplo `anuncio-adv-previdenciario`.
2. Envie todos os arquivos desta pasta para o repositorio.
3. No GitHub, acesse `Settings > Pages`.
4. Em `Build and deployment`, escolha `GitHub Actions`.
5. Confirme que o workflow `Deploy GitHub Pages` executou sem erro.
6. A URL final aparecera no resumo do deploy.
7. Use essa URL como destino inicial da campanha.

## Depois, se houver dominio proprio

1. Compre ou use um dominio profissional do escritorio.
2. Configure o dominio no GitHub Pages.
3. Adicione o arquivo `CNAME` com o dominio escolhido.
4. Atualize a URL final no Google Ads.

## Pontos para revisar antes de publicar

- Confirmar WhatsApp correto em `assets/site.js`.
- Confirmar que as imagens em `assets/brand/` carregam corretamente.
- Confirmar OAB e endereco exibidos na pagina.
- Confirmar se o Perfil da Empresa esta com telefone, horario e endereco corretos.
- Testar a pagina no celular.
- Testar clique no WhatsApp e no telefone.
